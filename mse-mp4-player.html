How to Use

  • Select an MP4 file using the file input above
  • Click "Extract Buffers" to parse the MP4 and extract init segments and media segments
  • The system will create track-specific init segments (moov boxes) preserving original track IDs
  • Click "Load Video" to initialize MSE and load the extracted buffers
  • Use the play/pause controls or the video player controls
  • Monitor the status panel and browser console for detailed processing information

Technical Details

  • Uses Shaka Player's MP4 parser for comprehensive segment extraction
  • Generates track-specific init segments with ftyp + filtered moov boxes
  • Preserves original track IDs in the reconstructed init segments
  • Filters mvex box to contain only trex entries for the target track
  • Groups moof+mdat pairs by track type into consolidated media buffers
  • Validates init segments before feeding to MSE SourceBuffers
  • Provides detailed logging for debugging and analysis

Key Implementation Features

  • Track-Specific Moov Generation: Creates separate moov boxes for each track containing only relevant metadata
  • Box Structure Preservation: Maintains proper MP4 box hierarchy and structure
  • Fragment Handling: Properly handles fragmented MP4 files with mvex/trex boxes
  • Validation: Validates generated init segments for proper ftyp and moov box presence
  • MIME Type Detection: Automatically detects appropriate MIME types based on extracted codec information
